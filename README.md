# 💬 Chat Application

A functional chat application built using **HTML, CSS, JavaScript, Node.js, and MySQL**.  
It provides a simple yet effective user interface where users can send and view messages, with chat history stored in a MySQL database.

## Features
- Clean and responsive chat UI
- Send and receive messages in real-time
- Messages stored securely in MySQL database
- Node.js backend with Express
- REST API for message handling

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Database**: MySQL

## Setup Instructions
1. Clone the repository  
   ```bash
   git clone https://github.com/your-username/chat-app.git
   cd chat-app

2. **Install dependencies**
   ```bash
   npm install

3. **Configure MySQL in server.js**
Update your MySQL username, password, and database name.

4. **Create database and tables using db.sql**
Import the db.sql file into your MySQL server.

5. **Run the server**
   ```bash
   node server.js

6. **Open the app**
Open index.html in your browser and start chatting
